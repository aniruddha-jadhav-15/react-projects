# 🛒 Shopping Cart

A simple shopping cart application built with **React** to practice state management, props, component communication, and dynamic rendering.

## ✨ Features

- 🛍️ Display products using dynamic data
- ➕ Add products to the cart
- 🔁 Track product quantities
- 🗑️ Remove products from the cart
- 💰 Calculate the total price dynamically
- ⚛️ Component-based architecture

## 🛠️ Built With

- React
- Vite
- JavaScript (ES6+)

## 📂 Component Structure

```text
App
└── ShoppingCart
    ├── ProductList
    │   └── ProductCard
    └── Cart
        └── CartItem
```

## 📚 What I Practiced

- React Components
- Props
- `useState` Hook
- Event Handling
- Rendering Dynamic Data with `map()`
- Array Methods
- Component Communication
- State Management
- Calculating Derived Data

## 🚀 Getting Started

```bash
npm install
npm run dev
```
