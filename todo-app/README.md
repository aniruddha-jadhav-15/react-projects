# 📝 Todo App

A simple Todo application built with **React** and **Vite** to practice React fundamentals such as component architecture, state management, props, and event handling.

## ✨ Features

- ➕ Add a new task
- ✅ Mark a task as completed
- 🗑️ Delete a task
- ⚛️ Component-based architecture

## 🛠️ Built With

- React
- Vite
- JavaScript (ES6+)
- CSS

## 📂 Project Structure

```text
src/
├── components/
│   ├── TodoInput.jsx
│   ├── TodoList.jsx
│   └── TodoItem.jsx
├── TodoApp.jsx
├── App.jsx
├── main.jsx
└── App.css
```

## 🚀 Getting Started

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd todo-app
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```
