# 👤 User Dashboard

A simple React application that displays a list of users using **React** and **Tailwind CSS**.

## ✨ Features

- 👥 Display user information
- 🎨 Responsive UI with Tailwind CSS
- ⚛️ Component-based architecture
- 📱 Clean and modern layout

## 🛠️ Built With

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)

## 📂 Project Structure

```text
src/
├── components
│   └── UserList.jsx
├── UserDashboard.jsx
├── App.jsx
├── main.jsx
└── index.css
```

## 🚀 Getting Started

```bash
npm install
npm run dev
```

- Props
- Rendering Lists
- Tailwind CSS
- Component Reusability
