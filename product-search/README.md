# 🔍 Product Search

A simple React application that allows users to search and filter products in real time. This project focuses on React fundamentals such as state management, props, component communication, and list rendering.

## ✨ Features

- 🔍 Search products by name
- ⚡ Real-time filtering
- 📦 Display products using dynamic data
- ⚛️ Component-based architecture
- 📱 Clean and responsive UI

## 🛠️ Built With

- React
- Vite
- JavaScript (ES6+)
- Tailwind CSS

## 📂 Component Structure

```text
App
└── ProductSearch
    ├── SearchBar
    └── ProductList
```

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📚 What I Practiced

- React Components
- Props
- useState Hook
- Event Handling
- Filtering Data
- Rendering Dynamic Data with `map()`
- Component Communication
- Tailwind CSS
